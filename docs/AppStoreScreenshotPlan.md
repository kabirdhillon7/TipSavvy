# TipSavvy App Store Screenshot Plan

Use realistic values and the current app UI. Avoid empty states unless a screenshot is intentionally demonstrating saved-tip management.

## Screenshot Story

1. Calculator: show an entered bill, 20% tip, three-person split, and round-per-person mode.
   - Caption: "Calculate and split tips fast"
2. Saved Tips: show demo saved calculations with sort/filter controls visible.
   - Caption: "Save the checks you want to remember"
3. Saved Detail: show copy/share, rename, delete, and per-person total.
   - Caption: "Copy or share the final amount"
4. Settings: show default tip, default split, app theme, haptics, privacy, support, and about sections.
   - Caption: "Set your defaults, theme, and privacy preferences"

## Capture Notes

- Launch with `-demo-data` for realistic saved tips.
- Use English and a US locale for App Store Connect consistency.
- Use light mode for the primary set unless creating separate dark-mode marketing images.
- Re-run after any App Store icon or Settings changes so screenshots match the shipped app.
